### 🚀 Featured Projects

#### [🔧 Jupyter Workflow Automation](https://github.com/kunal639/Jupyter-Workflow-Automation-v1.0)
A desktop GUI that removes friction from daily Jupyter usage — launch notebooks from saved project folders, auto-summarize notebook contents with HuggingFace models, and check `requirements.txt` compatibility before you even open a kernel.
`Python` `Tkinter` `HuggingFace` `Git integration`
**→ v2.0 in progress:** version tracking, diagnostics, AI-enhanced UI

#### 🧠 Real-Time Emotion Detection *(Hackathon Build)*
A dual-modality system that reads facial expression and vocal tone in real time to flag student distress in classroom settings, giving counselors actionable, timely alerts instead of relying on self-reporting.
`OpenCV` `Audio Classification` `Computer Vision`

#### 🔍 Malicious Domain Detection *(In Progress)*
An explainable ML pipeline that classifies malicious domains/IPs using DNS, WHOIS, and live threat-feed data — built around XGBoost and Random Forest so security analysts can see *why* a flag was raised, not just that it was.
`XGBoost` `Random Forest` `Explainable AI` `API Deployment`
