### 🚀 Featured Projects

#### 🔭 [ObserverModel — AI Runtime Observability Platform](https://github.com/kunal639/observermodel)

An AI-agent observability platform designed to analyze execution behavior and identify inefficient or potentially risky agent activity.

- Built a telemetry parsing pipeline for Claude Code execution logs.
- Implemented deterministic anomaly detectors for retry loops, repeated reads, excessive file enumeration, and security-sensitive behavior.
- Integrated Gemini-powered root-cause analysis with human approval before recommendations are surfaced.
- Developed token-cost attribution and historical execution analytics using BigQuery and Cloud Storage.
- Deployed the FastAPI application on Google Cloud Run.

`FastAPI` `Python` `Gemini` `BigQuery` `Cloud Storage` `Cloud Run`

- Integrated graph-based retrieval into the chatbot backend for context-aware responses.
- Led a six-member team.
- Designed workspace-specific knowledge bases, embeddable chat widgets, and confidence-based escalation to human agents.

`FastAPI` `Neo4j` `GraphRAG` `RAG` `NLP`

#### 🔐 Secure Gemini Journal

A multi-user AI journaling application with backend-enforced data isolation and selective AI response generation.

- Built using Next.js, Firebase Authentication, Firestore, Cloud Run, and Gemini.
